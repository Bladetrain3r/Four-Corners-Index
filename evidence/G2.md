# G2 evidence — 2026-09-29

GATES.md G2: one adapter per source (fetch, live or fixture, then a normalised series in the common schema); tests per adapter on its fixtures (parse succeeds, schema validates, units right, no silent NaN, a deliberately corrupted fixture fails loudly naming the source).

| Source | Module | Test file | Corrupted-fixture cases that raise `[source] ...` |
|---|---|---|---|
| Eurostat | `pipeline/eurostat.py` | `tests/test_eurostat.py` | renamed dimension, list-form `value`, non-numeric value, wrong unit |
| EIA | `pipeline/eia.py` | `tests/test_eia.py` | wrong units, renamed column, null value, NaN value, unknown fuel, error body, wrong frequency |
| Ember | `pipeline/ember.py` | `tests/test_ember.py` | renamed header (both file families), old long format, unknown source, blank value, text value, unknown country, mid-month date |
| ECB | `pipeline/ecb.py` | `tests/test_ecb.py` | renamed column, wrong series type, unexpected currency, blank / zero / text rate |
| World Bank | `pipeline/worldbank.py` | `tests/test_worldbank.py` | missing sheet, not a workbook, renamed column, changed unit, text value, bad period label, missing update line |

Shared: `pipeline/common.py` (SourceError starts every message with `[source]`, no-NaN point validation, deterministic JSON), `pipeline/http.py` (bounded retries, https only, secret redaction), `pipeline/registry.py` (16 live requests, each with its fixture), `pipeline/fetch.py` (modes live, fixture, auto). Structural rules are tests too: no adapter imports another, every module under 400 lines, the pipeline imports nothing outside the standard library (`tests/test_layout.py`).

## Not proved / open
- Ember hourly prices are not parsed (schema periods are dates); daily and monthly are. SPEC's two-year hourly retention is a G4/G6 question.
- The live queries pull full histories (Ember's two files are 28 MB and 16 MB); raw snapshot storage (Release assets, SHA-256 manifest) is G4/G6.
- Eurostat non-EU rows (for example Türkiye, United Kingdom) are not requested: the adapter lists the 27 member states explicitly.
- No CBR, Eskom, CAISO, ERCOT, NYISO, MISO or carbon adapters, by decision (STOP-1 answers).
