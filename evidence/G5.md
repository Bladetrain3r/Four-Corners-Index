# G5 evidence: the static dashboard (2026-09-30)

**Claim:** the site is self-contained static HTML/CSS/JS reading generated JSON; every headline figure shows value, month, publication date, status, source and quality badge; a gap is shown as a gap with its reason; the currency and weighting toggles change the numbers as labelled; it fits a 390 px phone; it makes no request to any host but its own.

## What was run
- `python -m pipeline.publish` builds `site/data/*.json` (about 470 KB) and `site/downloads/` (195 files) from `data/`; both are gitignored and generated at deploy.
- `pytest tests/test_site_static.py` (CI): every page has lang, viewport, title, one h1, a noscript note; no external URL in any script, style, import or fetch; local imports and links exist; text tokens reach 4.5:1 on every surface in light and dark (mutation check: a grey `--text-secondary` turns it red at 2.6:1).
- `pytest tests/test_site_browser.py` (local; skipped where Playwright or Chromium is missing, so CI does not run it): 16 tests in headless Chromium.
  - Tiles equal the last rows of `index.json` to three decimals, at 1280 and 390 px, with status, month, published date, source and badge.
  - Every region card is either a value with its source or "No source" with the reason from `regions.json` (at least eight gaps).
  - USD, EUR, ZAR and the three weightings change the tile value to the independently computed number; a non-headline variant says so (mutation check: inverting the EUR conversion turns it red).
  - Keyboard: skip link first; a chart takes focus, the arrow key reads a dated value aloud (aria-live); "View as table" shows 140+ rows.
  - Every page, and Russia, China and EU region pages, load with no console error, no request to any other host, and `scrollWidth <= 390` at phone width.
  - Every one of the 190+ download links returns 200 and is non-empty.
  - Dark theme is selectable and persists across a reload.
- Screenshots (`evidence/G5/`, 11 files, 6.6 MB): home at desktop, phone and dark; indices, EU, China and Russia regions, sources and downloads. Produced by `FCI_SCREENSHOTS=1 pytest tests/test_site_browser.py`.

## Result
200 tests pass locally (static 13, browser 16); ruff clean; tracked repo size 15 MB.

## Not proved, stated plainly
- CI does not run the browser tests, so a rendering regression would not turn CI red; the screenshots here are the proof for this commit.
- Series colours on the light surface fall below 3:1 for some slots (the validation gave WARN); the design relieves this with direct labels, legends and a table view for every chart, and the static test pins that those exist. It does not prove they are sufficient for a reader with low vision.
- Screen-reader behaviour was tested through the aria-live text, not with a screen reader.
- The site has never been served from GitHub Pages; that is G6 and Ziggy's act.
