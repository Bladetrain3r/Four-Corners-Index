# G7 evidence: the air quality tab (2026-10-01)

**Claim:** a new page, "Air quality", shows mean annual PM2.5 exposure for all six regions (EU, US, China, Russia, South Africa, UK) from the World Bank's WDI indicator `EN.ATM.PM25.MC.M3`, with the year, source, licence line and quality badge on every figure, the WHO 2021 guideline, the same-year fuel mix beside it, a 1990 to 2023 chart with a table view, downloads, and attribution naming IHME. It is a tab, not an index. Nothing is invented: a year the World Bank has not published is a recorded gap.

## What was built
- `pipeline/worldbank_wdi.py` (new adapter, one more request of the `worldbank` source, optional so the pinned launch bundle still builds); schema layer `air`; request `wdi_pm25` in the registry with a fixture from a real response (96 rows, 2010 onward, fetch date and URL in `fixtures/worldbank/MANIFEST.json`).
- `data/manual/air_quality.json` (indicator text, WHO guideline with its verification note, method paragraphs), `pipeline/site_air.py` (`air.json`: per region value, year, ratio to the guideline, series, annual fuel mix), `site/air.html` and `site/js/air.js`, a nav entry, `sources.json` attribution (World Bank and IHME, what we change, removal on objection).

## Evaluations run
1. **Adapter** (`tests/test_worldbank_wdi.py`, 10 tests): six regions, schema valid, unit µg/m³, confidence `high_latency`; values equal the published rows; the 12 null rows (2024 and 2025) are gaps with a reason and are never filled; five mutated responses (unknown area, negative value, wrong indicator, missing header date, missing region) fail loudly naming `[worldbank]`; an API error object and a mostly-empty response are refused.
2. **Live**: the real API through the real fetch layer gives 204 points (1990 to 2023) and 12 gaps, `as_of 2026-07-13`; every fixture row equals the live row. Latest values (µg/m³, 2023): China 32.0, South Africa 27.7, Russia 11.6, EU 11.0, UK 9.5, US 7.0.
3. **Site data** (`tests/test_site_air.py`, 6 tests): all six regions in order with year 2023 and the published value; ratio to the guideline recomputed (mutation check: multiplying instead of dividing turns it red); fuel shares sum to 1 within 1e-4 (Ember rounds its components; the worst region-year is off by 2.9e-5, bound chosen after looking); only complete years (twelve months) are used; without the series the page says "no data yet" and keeps its method text.
4. **Browser** (`tests/test_site_browser.py`, 1280 and 390 px): each card shows value, year, licence line, "× the WHO guideline", badge and as-of date; the table beside it is sorted by value; the guideline verification note and the "not an index" text are present; "View as table" shows every year; no console error, no request to any other host, no horizontal scroll; the no-data state renders its notice and no cards. Screenshots: `evidence/G5/air_desktop.png` and `air_phone.png`.
5. **A live rehearsal of the daily run with the new request** (`pipeline.daily` against a temporary copy, all 20 requests live): no failures; one new snapshot (`worldbank/wdi_pm25`); the build wrote `worldbank__wdi_pm25.csv` with 204 rows; one ledger line was appended, retail 2025-09 provisional to final at the same value 0.155838, because its EIA input turned 12 months old (the designed revision path). The rehearsal also found a real bug, fixed here: a connection cut off mid-download (`IncompleteRead` on a 28 MB file) escaped as a raw exception that would have ended the run with no issue and no health record. `http.get` now retries it and then raises a `SourceError`; the daily run also records any unexpected error from one source as that source's failure and carries on (tests for both).
6. Suite: 245 tests pass locally; ruff clean; repo 22 MB.

## Not proved, stated plainly
- **The WHO guideline value (5 µg/m³) was not read from WHO.** WHO's own pages show it only in an image table; the value is as quoted in a peer-reviewed paper (Global Challenges 2024). The page says so; a person should check it against the WHO table.
- **The IHME upstream terms were not read** (their page returned 403). The World Bank page states `License: CC BY-4.0` and the attribution names IHME. Ziggy's decision (2026-10-01): acceptable unless someone objects, then remove it.
- **No air data is on the site until the first daily run after merge**: the series is not committed from this session (its raw bytes could not go to a Release asset from here, and the daily job does that). Until then the tab says "No data yet". The first dispatch of `daily` after the merge fills it.
- The series is modelled and annual; it is not a measurement, and it says so.
